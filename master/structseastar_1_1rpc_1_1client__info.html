template<typename T>
T & seastar::rpc::client_info::retrieve_auxiliary ( const sstring & key)
inline

Returns a reference to the auxiliary object attached under key.

If nothing was attached under key (for example because the verb that was supposed to call attach_auxiliary() failed before doing so), the connection is aborted and missing_auxiliary_error is thrown. Use retrieve_auxiliary_opt() to probe for a key without side effects.
