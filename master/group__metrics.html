template<std::invocable F>
collector_ptr< std::invoke_result_t< F > > seastar::metrics::make_collector ( F f)

Create a collector, a value computed once per collection of the metric values, from which several metrics take their values.

For example:

auto status = make_collector([this] { return _server.get_status(); });
_metrics.add_group("my_group", {
make_gauge("commit_index", status, &status_type::commit_index, description("commit index")),
make_gauge("apply_index", status, &status_type::apply_index, description("apply index")),
});

Definition metrics.hh:617

Every collection of the values of this shard's metrics calls f once, before it evaluates any metric, provided at least one metric made from the collector is registered and enabled. Its metrics then read what that call returned. An exception thrown by f fails the collection, like one thrown by a metric function. f must not register or unregister metrics.

The metrics made from the collector keep it alive.

template<typename T, collector_projection< T, double > Projection>

const collector_ptr< T > & c,
Projection proj,
description d = description(),

Gauge whose value is taken from the snapshot of a collector.

proj extracts the value from the snapshot. It is either a pointer to a data member of the snapshot or anything callable with the snapshot.

For example:

auto status = make_collector([this] { return _server.get_status(); });
_metrics.add_group("my_group", {
make_gauge("commit_index", status, &status_type::commit_index, description("commit index")),
make_gauge("lag", status, [] (const status_type& s) { return s.commit_index - s.apply_index; }, description("lag")),
});
