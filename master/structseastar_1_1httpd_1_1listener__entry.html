seastar::httpd::listener_entry Struct Reference

Detailed Description

One listening socket of an http_server, and the accept loop that feeds it.

A listener is identified by this object rather than by the address it is bound to: a wildcard bind shares its address with nothing and yet accepts connections whose own local address is a concrete one, and the proxy protocol replaces an accepted socket's local address outright, so an address identifies a listener only by accident.
