seastar::data_sink Class Reference

Detailed Description

Pushes bulk data to a provider, such as a TCP connection, a disk file or a memory buffer.

Note
All methods must be called sequentially. That is, no method may be invoked before the previous method's returned future is resolved, and the sink may not be destroyed while a put() is outstanding.
