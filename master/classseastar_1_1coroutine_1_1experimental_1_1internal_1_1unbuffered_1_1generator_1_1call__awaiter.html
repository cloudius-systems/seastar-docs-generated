seastar::coroutine::experimental::internal::unbuffered::generator< Ref, Value >::call_awaiter Class Reference

Detailed Description

template<typename Ref, typename Value>
class seastar::coroutine::experimental::internal::unbuffered::generator< Ref, Value >::call_awaiter

Get the next value from the generator. Returns std::optional containing the next value, or std::nullopt if done. For reference types, returns std::optional<std::reference_wrapper<T>>.

Example usage:

auto gen = my_generator();
while (auto value = co_await gen()) {
process(value->get()); // for references
process(*value); // for values
}
