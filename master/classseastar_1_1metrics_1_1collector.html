Detailed Description

template<typename T>
class seastar::metrics::collector< T >

A value computed once per collection of the metric values and shared by the metrics made from it.

Several metrics often derive from one snapshot of some state. A collector takes that snapshot once per collection of the shard's metrics, before any metric is evaluated, and the metrics made from it read their values from the snapshot, so they agree with each other. The snapshot is dropped once the collection is over. A collection does not run a collector whose metrics are all disabled.

Create it with make_collector() and make metrics from it with the overloads of make_gauge(), make_counter(), make_histogram() and make_summary() that take a collector.

#include <seastar/core/metrics.hh>
