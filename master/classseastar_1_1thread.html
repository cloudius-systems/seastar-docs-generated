Seastar threads

Detailed Description

thread - stateful thread of execution

Threads allow using seastar APIs in a blocking manner, by calling future::get() on a non-ready future. When this happens, the thread is put to sleep until the future becomes ready.

◆ switch_to()

scheduling_group seastar::thread::switch_to ( scheduling_group new_sg)
static

Switch the current thread to a different scheduling group.

Moves the currently running thread to new_sg: subsequent execution of this thread (including the remainder of the calling function) is accounted for, and scheduled as, new_sg instead of whatever group the thread was created or last switched into.

If new_sg is already the thread's current scheduling group, this call is a no-op: it returns immediately without yielding. Otherwise, it is equivalent to yield() into the new group: other threads/fibers get a chance to run before this thread resumes.

This is the thread counterpart of coroutine::switch_to, which does the same for coroutines.

Parameters
new_sgthe scheduling group to switch to
Returns
the scheduling group the thread was in before the switch, so the caller can switch back later if desired.

Example:

seastar::thread th([sg] {
... // do some preliminary work
auto prev_sg = seastar::thread::switch_to(sg);
... // do some work accounted to sg
seastar::thread::switch_to(prev_sg);
... // do some more work
});
